## Projeto em destaque · LexisPredict

O [LexisPredict](https://github.com/W1CAPITAL/LexisPredict) reúne acompanhamento processual, gestão de carteira e histórico de atendimento em uma plataforma.

| Na operação | No LexisPredict |
| :--- | :--- |
| Acompanhar movimentações processuais | Monitoramento automatizado para apoiar a triagem |
| Identificar quem cuida de cada processo | Responsável pela carteira separado de quem realizou o atendimento |
| Preparar documentos recorrentes | Geração de minutas com apoio de IA |

## O que me interessa construir

- **Automação jurídica** para reduzir consultas repetitivas e facilitar o acompanhamento de processos.
- **Aplicações web** que dão à equipe acesso ao histórico e às informações necessárias para atender cada caso.
- **Dados operacionais** que ajudam a identificar pendências e distribuir o trabalho.
